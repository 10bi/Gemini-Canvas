# 🚀 Gemini Canvas

A simple, clean, and responsive tool dashboard. All tools are loaded dynamically from a single `data.json` file — no coding needed to add new tools.

---

## ✨ Features

- 📦 **JSON-driven** — add or remove tools by editing `data.json`
- 📱 **Fully responsive** grid layout
- 🖱️ **Fully clickable cards** — click anywhere on a card to open the link
- ⚡ **Zero dependencies** — pure HTML + CSS + JS, no frameworks
- 🖼️ **Logo optional** — tools can be added without any image
